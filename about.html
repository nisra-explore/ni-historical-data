NI Historical Data Explorer

About the NI Historical Data Explorer

The NI Historical Data Explorer is a tool that helps you find and use official statistics.

You can use it to explore, view and download data from the NISRA Data Portal.

It is designed to be simple to use. You do not need technical skills to get started.

What you can do

With the Data Explorer, you can:

  • Search for datasets
  • Filter data by topic, place or time
  • View data as charts, maps or tables
  • Download datasets
  • Export data for your own analysis

The NISRA Data Portal provides open, machine-readable data to support transparency, reuse, and innovation.
